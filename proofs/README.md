# Verified StudioNet markets

The primary proof set contains **29 distinct FINALIZED / MAJORITY_AGREE transactions** on gasless StudioNet, chain 61999: 27 successful executions and two expected contract rejections. Three controlled disposable signing wallets participate in each market. Raw/admitted/escrow inventory and quote-credit conservation are checked after every step. Fixtures demonstrate abstract native units and newly endowed quote credits; they do not establish external delivery or backing.

The [combined fresh verification report](verification.json) confirms all twenty-nine receipts, actual decoded calldata, signer and target, complete final votes, exact deployed source and all three full current ledgers. The independent JavaScript oracle expands orders into individual unit tickets and checks exact fills, trades, escrow refunds and balance transitions. Offline verification also passes. No ambiguous send is automatically repeated. Direct tests use web/model mocks while explicitly invoking validator callbacks.
